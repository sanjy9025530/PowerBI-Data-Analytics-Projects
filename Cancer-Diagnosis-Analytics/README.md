# Cancer Diagnosis Analytics Dashboard

## Overview

An interactive Power BI dashboard developed for analyzing breast cancer diagnosis data and generating data-driven insights.

## Tools Used

- Power BI
- Data Cleaning
- Data Visualization
- DAX
- Interactive Dashboard Design

## Dashboard Features

- Total patient analysis
- Malignant and benign diagnosis distribution
- Tumor measurement analysis
- Diagnosis-based comparisons
- Interactive filtering
- KPI-based executive overview
