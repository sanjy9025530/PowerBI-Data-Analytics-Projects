# Power BI Data Analytics Projects

A collection of Power BI projects developed to demonstrate practical skills in data analysis, data visualization, dashboard development, and business intelligence.

## Projects

### 1. Cancer Diagnosis Analytics Dashboard

An interactive dashboard for analyzing breast cancer diagnosis data.

**Key areas:**

* Patient and diagnosis analysis
* Malignant vs. benign case analysis
* Tumor measurement analysis
* Diagnosis-based comparisons
* Interactive filtering and visualization

[View Project](./Cancer-Diagnosis-Analytics)

---

### 2. Crime Analysis Dashboard

An interactive dashboard for analyzing crime patterns, trends, and case outcomes.

**Key areas:**

* Total crime analysis
* Solved vs. unsolved cases
* Monthly crime trends
* Crime-type analysis
* Year-based analysis
* Interactive filtering

[View Project](./Crime-Analysis)

---

### 3. Electric Vehicle Sales Analytics Dashboard

An interactive dashboard for analyzing electric vehicle sales, market trends, market share, and charging infrastructure.

**Key areas:**

* Global EV sales analysis
* Year-wise sales trends
* Country-wise EV sales
* EV market share analysis
* Charging infrastructure analysis
* EV market evolution
* Interactive filtering and decision-oriented insights

[View Project](./EV-Sales-Analytics)
