# Electric Vehicle Sales Analytics Dashboard

## Overview

An interactive Power BI dashboard developed to analyze global electric vehicle sales, market trends, charging infrastructure, and EV market insights.

## Tools Used

- Power BI
- Data Cleaning
- Data Analysis
- DAX
- Data Visualization
- Interactive Dashboard Design

## Dashboard Features

- Global EV sales analysis
- EV sales trends by year
- Country-wise EV sales comparison
- EV type market share
- EV market share evolution
- Charging infrastructure analysis
- Interactive filters and slicers
- Decision-oriented analytical insights
