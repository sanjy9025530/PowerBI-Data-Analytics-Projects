# Crime Analysis Dashboard

## Overview

An interactive Power BI dashboard developed to analyze crime patterns, trends, and case outcomes across different crime categories and time periods.

## Tools Used

- Power BI
- Data Cleaning
- Data Analysis
- DAX
- Data Visualization
- Interactive Dashboard Design

## Dashboard Features

- Total crime analysis
- Solved vs. unsolved crime analysis
- Monthly crime trends
- Crime-type distribution
- Year-based filtering
- Problem-status filtering
- Interactive visual analysis
